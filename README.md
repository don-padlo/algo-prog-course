ПР1. Ответы на контрольные вопросы
1.C# не даст запустить файл,если в нём есть ошибка. В Python файл запустится,но остановится, когда дойдёт до строчки с ошибкой.

2.Собирает(компилирует) и запускает файл

3.В папке bin хранится скомпилированная программа. В obj хранятся промежуточные файлы. Они пересоздаются заново, при запуске программы,их можно не хранить.

4.git commit сохраняет изменение на компьютере,а git push отправляет изменения в репозиторий.

5.Интерполяция строк вставляет переменные внутрь текста через фигурные скобки, а конкатенация соединяет отдельные куски текста и переменные. Предпочтительнее пользоваться интерполяцией,с ней код становится более читаемым.

6.Дробная часть отбросится. Чтобы избежать этого нужно изменить один int на double.

7.Константа не даст заменить значение переменной,после первого назначения значения. Можно использовать для указания даты рождения,или данных,которые никогда не могут измениться.

8.Top-level statements функция, которая позволяет писать исполняемый код напрямую в файле без необходимости явно объявлять класс Program и метод Main.

контрольные вопросы

1 double хранит числа в двоичной системе, поэтому возможны ошибки округления. Например, 0.1 + 0.2 может дать не ровно 0.3. decimal точнее подходит для денежных расчётов.

2.byte хранит значения от 0 до 255. При переполнении результат зависит от контекста: в checked будет исключение OverflowException, а без checked значение может перейти через границу диапазона.

3.Компилятор определяет тип переменной во время компиляции по значению справа. В Python тип определяется во время выполнения.

4.Строку. Если ввод закончился, может вернуть null.

5.Parse при некорректном вводе выбрасывает исключение. TryParse просто возвращает false, без исключения.

6.Это значит, что преобразовать строку в int не удалось. В out-переменную попадёт значение 0.
